# Ветка files — публичное хранилище файлов для Telegram

Сюда скрипт `tools/publish.py` (ветка main) кладёт файлы в папку `f/`.
Ссылка на файл: https://raw.githubusercontent.com/DmitriyIvanovich86/delo-taganroga/files/f/<имя>

Репозиторий публичный: персональные данные клиентов, договоры и индивидуальные цены сюда не кладутся.
Сайт на Vercel из этой ветки не собирается.
